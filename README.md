### ⭐ Featured Project — Edu Bridge *(Graduation Project)*

A university management platform with a **web dashboard** and a **Flutter mobile app**, serving 6 roles: Student, Teacher, Parent, Admin, Head of Department, and Student Affairs.
Built by a team of 4 — I'm the **second-largest contributor** to both the backend and the mobile app.

**My contributions**
- 💬 **Chat module** — one-to-one and group chat across all roles, on web and mobile
- 🔒 **Security & performance** — patched IDOR and XSS vulnerabilities, added API rate limiting, background queues, database indexing, and a single-active-session policy
- 🧑‍🎓 **Student module end-to-end** — Flutter screens and the Laravel APIs behind them (dashboard, attendance, schedule, assignments, notifications)
- 🧭 **Multi-role workflows** — student services, student-affairs screens, parent appointment requests and summons
- 🧑‍💼 **Face verification** (ArcFace) and a Telegram bot integration
- 🧹 **Refactoring** — split a monolithic admin controller into 9 focused controllers and extracted FormRequest validation
- 📄 **Reports** — PDF / Excel exports, academic cards, and schedule generation

**Stack:** Laravel 12 · Sanctum · Pusher · MySQL · Flutter · Provider · Dio
